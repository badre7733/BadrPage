El proyecto

Una IA útil, sin depender de la nube.

BADR AI es un proyecto de investigación que explora cómo crear un asistente conversacional que se ejecute en el propio dispositivo. El objetivo es ofrecer una herramienta práctica, accesible y capaz de funcionar sin conexión a Internet.

⌁

Sin Wi-Fi

Una vez instalado el modelo y sus componentes, la versión local está diseñada para responder sin Internet.

◈

Privacidad

Las preguntas pueden procesarse en el propio dispositivo sin enviarlas a servidores remotos.

⌘

Windows Portable

El proyecto contempla una versión portable optimizada para ordenadores con sistema Windows.

Compromiso ambiental

Tecnología con conciencia ambiental.

Menos dependencia de la nube

BADR AI apuesta por la ejecución local: las consultas no necesitan viajar a servidores remotos, lo que puede reducir la dependencia de servicios en la nube.

  • No utiliza agua directamente durante su funcionamiento en el dispositivo.
  • No necesita enviar cada pregunta a Internet para generar una respuesta local.
  • Busca aprovechar el hardware disponible y reducir la dependencia de infraestructura remota.

Transparencia: no sería correcto afirmar que la huella ambiental total es cero. El dispositivo consume electricidad y fabricar hardware también tiene impacto. El consumo real depende del equipo y del modelo.

Descargas

Lleva BADR AI contigo.

Sigue los 3 pasos en orden: instala primero el motor de IA, descarga el modelo y después abre la aplicación.

WINDOWS · MOTOR
PASO 1 · OBLIGATORIO

Motor de IA para Windows

BADR AI utiliza Ollama para ejecutar el modelo de lenguaje localmente. Instala este motor en el ordenador antes de utilizar la versión de Windows. La primera instalación necesita Internet.

  1. Descarga el instalador oficial de Ollama.
  2. Ejecuta el instalador y termina la instalación.
  3. Después, instala el modelo siguiendo el paso 2.
Descargar motor oficial ↓
WINDOWS · MODELO
PASO 2 · OBLIGATORIO

Modelo de IA Qwen 2.5 3B

El motor Ollama no incluye automáticamente este modelo. Después de instalar Ollama, abre la terminal de Windows y ejecuta el comando indicado para descargarlo.

ollama run qwen2.5:3b

La descarga del modelo requiere Internet la primera vez. Después podrá ejecutarse localmente.

WINDOWS · APP
PASO 3 · APLICACIÓN

BADR AI portable para Windows

Descarga la aplicación BADR AI. Para utilizar el chat, el motor Ollama y el modelo Qwen 2.5 3B deben estar instalados y disponibles en el ordenador.

El TDR

De la idea al asistente local.

Líneas de trabajo

  1. Investigar cómo funcionan los modelos de lenguaje y los chatbots.
  2. Preparar datos y experimentar con tokenización, entrenamiento y evaluación.
  3. Crear una interfaz para preguntar y recibir respuestas localmente.
  4. Explorar la adaptación a Windows portable.
  5. Documentar resultados, limitaciones y posibles mejoras.
